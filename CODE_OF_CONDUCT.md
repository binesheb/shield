# Code of Conduct

SHIELD is a technical open-source project. We expect contributors to collaborate respectfully and focus on evidence, engineering quality, and defensive security.

## Expected behavior
- Be respectful and constructive.
- Discuss technical evidence rather than people.
- Welcome contributors with different experience levels.
- Protect privacy and project security.

## Unacceptable behavior
- Harassment or discrimination.
- Personal attacks or threats.
- Deliberate disruption.
- Publishing private information.
- Malicious use of project infrastructure.
- Intentionally harmful code without authorization.

## Enforcement

Maintainers may remove comments, reject contributions, or restrict participation when behavior violates this code. Sensitive concerns should be reported privately to maintainers.
